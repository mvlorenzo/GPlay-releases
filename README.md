# GPlay-releases

This repository is dedicated to APK releases for GPlay, the CarPlay app for modified Geely HU systems based on the DiPlay fork.

It contains release artifacts, versioned APK builds, and installation-related documentation only. This is not a source-code repository.

## Compatibility

This repository is intended for GPlay APK builds designed for modified Geely HU systems and related CarPlay use cases.

## Notes

- This repo is for APK distribution only.
- Source code is not included here.
- Use the release files and documentation provided in this repository for installation and updates.
